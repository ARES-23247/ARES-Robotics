# Contributing

Contributions are accepted under Apache License 2.0, the repository's outbound license. Under Apache-2.0 section 5, an intentionally submitted contribution is provided under that license unless the contributor explicitly states otherwise and the maintainers agree before inclusion.

Contributors must certify the Developer Certificate of Origin 1.1 by adding a `Signed-off-by` line to each commit:

```text
Signed-off-by: Name <email@example.com>
```

Use `git commit --signoff` to add the line. The sign-off certifies that the contributor created the work or has the right to submit it under the repository license. Do not submit third-party code without identifying its source and license, and do not remove existing copyright, license, or attribution notices.

New ARES-authored source files should identify their license with the language-appropriate SPDX header, for example:

```kotlin
// SPDX-License-Identifier: Apache-2.0
```
