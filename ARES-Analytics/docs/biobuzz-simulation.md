# BIOBUZZ integration

BIOBUZZ runs through Dashboard Local Sim and its existing Field 2D widget. Field Editor owns the shared field document. There is no practice tab or separate simulator window.

The implementation plan and verification record are in [biobuzz-dashboard-plan.md](biobuzz-dashboard-plan.md). The bundled [Robot Builder example guide](../../ARES-FTC/biobuzz/docs/BIOBUZZ.md) describes controls, generated mechanisms, physics assumptions, and deferred features.
