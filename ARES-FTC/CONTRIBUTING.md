# Contributing

ARES-authored contributions are accepted under Apache License 2.0. Do not relicense or remove notices from FIRST-owned files, and keep team features out of `FtcRobotController/`.

Contributors must certify the Developer Certificate of Origin 1.1 by committing with `git commit --signoff`. The resulting `Signed-off-by` line certifies that the contributor created the work or has the right to submit it under the applicable license.

Third-party code must include its provenance and license. A contribution touching inherited FTC SDK material must preserve `BSD-3-Clause-Clear` identification and the FIRST notice in `LICENSES/BSD-3-Clause-Clear.txt`.

New ARES-authored source files should identify their license with the language-appropriate SPDX header, for example:

```kotlin
// SPDX-License-Identifier: Apache-2.0
```
