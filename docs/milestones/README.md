# ARES Robotics Milestones & Historical Architecture Records

This directory contains historical architecture reviews, foundation specifications, RFCs, and milestone completion records from earlier phases of the ARES Robotics suite.

These documents serve as immutable design rationales and historical references. Active development guidance is located in [docs/agents/WORKSPACE_GUIDE.md](../agents/WORKSPACE_GUIDE.md) and repository maintainability policy is defined in [MAINTAINABILITY.md](../../MAINTAINABILITY.md).
