# Contributing

ARES-authored contributions are accepted under Apache License 2.0. Contributors must certify the Developer Certificate of Origin 1.1 by committing with `git commit --signoff`.

The resulting `Signed-off-by` line certifies that the contributor created the work or has the right to submit it under the applicable license. Do not submit third-party or vendor code without identifying its provenance and license, and do not remove existing WPILib, FIRST, CTRE, or other attribution notices.

New ARES-authored source files should identify their license with the language-appropriate SPDX header, for example:

```kotlin
// SPDX-License-Identifier: Apache-2.0
```
